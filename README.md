# DP-NSA: Deep Polyclonal Immunity

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23695241.svg)](https://doi.org/10.5281/zenodo.23695241)

Code, per-seed results and analysis scripts for

> J. Domínguez, F. J. Serradilla. *Deep Polyclonal Immunity: Label-Efficient Anomaly Detection through Supervised Geometric Learning.* Submitted to *Neurocomputing*.

DP-NSA reformulates Negative Selection as a differentiable geometric problem: a residual encoder learns a latent space in which normality is covered by anisotropic ellipsoids with learned covariance, and labelled anomalies shape that region through a repulsion term. A polyclonal repertoire of such detectors is trained by gradient descent instead of rejection sampling.

Every table, figure and in-text number of the paper can be regenerated from the released per-seed results with one command, and the test suite checks that they match the manuscript.

## Repository layout

```
dpnsa/          the method: ensemble (NSARepV23Ensemble), core geometry and training, encoder, data loading
baselines/      the ten baselines: shallow (Isolation Forest, One-Class SVM, XGBoost, ...) and deep (Deep SVDD, Deep SAD, DevNet, ...)
experiments/    one script per experiment of the paper
analysis/       tables, figures, statistical tests and in-text numbers, from the per-seed CSVs
scripts/        reproduce.py, run_experiment.sh, smoke_test.sh
results/paper/  per-seed results used in the paper (5 seeds, every configuration)
tests/          reproduction and code tests, with the manuscript's tables as reference
data/           where the datasets go (not distributed; see data/README.md)
```

## Installation

Python 3.12.3 and, to run the experiments, a CUDA GPU.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt            # full environment (experiments)
# or, to regenerate tables and figures only (CPU, no PyTorch):
pip install -r requirements-analysis.txt
```

## 2. Re-run the experiments (GPU)

Download the datasets first: `python scripts/download_data.py` (details in `data/README.md`). Experiments write to `results/runs/` and never overwrite `results/paper/`. To analyse your own runs: `DPNSA_PAPER_RESULTS=results/runs python scripts/reproduce.py`.

| Experiment | Section | Command used for the paper |
|---|---|---|
| Benchmark | 5.1 | `scripts/run_experiment.sh exp1 CreditCard Shuttle Mammography,Annthyroid Musk,Satimage,ECG5000 Arrhythmia,Cardio,Ionosphere` |
| Label scarcity | 5.2 | `scripts/run_experiment.sh exp6 CreditCard Shuttle Mammography Annthyroid Musk Satimage ECG5000,Cardio Arrhythmia,Ionosphere` |
| Ablation | 5.3 | `scripts/run_experiment.sh exp2 CreditCard Shuttle Mammography Annthyroid Musk,Satimage ECG5000,Cardio Arrhythmia,Ionosphere` |
| Granularity and repertoire | 5.4 | `scripts/run_experiment.sh exp5 CreditCard,Mammography,Shuttle,Arrhythmia` |
| Shrinkage coefficient | 5.4 | `scripts/run_experiment.sh exp7 Arrhythmia Musk Mammography CreditCard` |
| Latent projection | 5.5 | `EXP3_DATASETS=Cardio,Mammography,Musk,Satimage python experiments/exp3_latent_projection.py` |
| Trend test and saliency control | 5.2, 5.6 | `python experiments/exp9_trend_saliency.py` |

After the per-group runs of exp1, exp2, exp6 and exp7 finish, merge them with `python experiments/<script>.py --merge`. Seeds are 100–104 (`DPNSA_SEEDS` overrides them).

Before a long run, `scripts/smoke_test.sh` runs every experiment on Ionosphere with one seed (about 15 minutes) and checks the outputs.
